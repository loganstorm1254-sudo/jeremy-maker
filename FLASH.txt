Jeremy Bot 2.6.55 — Verity MAX volume (CQRobot enclosed)

PINS
----
Power switch:
  Either pin -> D25
  Other pin  -> GND
  ON = text + lights + Verity MAX until OFF

Speaker — CQRobot Enclosed (Amazon B0738NLFTG), NO board GND:
  Either pin -> D26
  Other pin  -> D27
  Swap the two wires if quiet.
  Drive = hard differential GPIO (~6.6Vpp). Bass cut in audio — volume not mud.

LEDs (no GND):
  BLUE   LONG->D2    SHORT->D23
  RED    LONG->D18   SHORT->D5
  YELLOW LONG->D19   SHORT->D13

FLASH
-----
1. Arduino → File → Open → jeremy_bot.ino (this whole folder)
2. Board: ESP32 Dev Module · Upload
3. Close Serial Monitor → Jeremy Studio
Or paste BOT_CODE_2.6.55.txt (song embedded, large).
