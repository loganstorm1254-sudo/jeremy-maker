Install guides

OLED screen
  • VCC → 3V3
  • GND → GND
  • SDA → D21
  • SCL → D22

128×64 SH1106. Shows eyes, uptime, version, and switch text.

LEDs
  • Blue long → D2 · short → D23
  • Red long → D18 · short → D5
  • Yellow long → D19 · short → D13

No board GND on the LEDs. Prefer 220Ω on each long leg. Unplug if hot.

Speaker
  • Either pin → D26
  • Other pin → D27

CQRobot enclosed — no board GND. Swap wires if quiet. Plays verity-hello while switch is on.

Power switch
  • Either pin → D25
  • Other pin → GND

Pins are identical either way. ON runs the switch program for the parts you have.
